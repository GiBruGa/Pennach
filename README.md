# Pennac'h

Suivi d'entraînement pour rameur électromagnétique **Merach R15 Pro**, connecté en Bluetooth (Web Bluetooth / FTMS) directement depuis le navigateur — aucune installation d'application requise.

Voir [SPEC.md](./SPEC.md) pour le cahier des charges complet.

## Compatibilité

Nécessite **Chrome ou Edge sur Android** (Web Bluetooth). Non supporté sur Safari iOS.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
